# Tumble Toys: Aviation releases

Windows and native Linux packages for Tessera Hub. Both platform archives and SHA256SUMS.txt are published together after their build checks pass.

Builds run in the private game source repository, preserving source confidentiality. Only packaged players are published here. No Steam upload is part of this workflow.

## Energy shield and AI update

- Hold Shift or controller Left Trigger to knock movable props over without downing your aircraft. Walls and floors remain solid.
- A bright, close-fitting green-gold energy shield indicates protection; there is no PHASING text overlay.
- Toggle the engine with Space, D-pad Down, or Back.
- AI racers start separately. Ring Trail and Scavenger Flight respect the selected ring count.
- Setup menus have smaller centered controls and descriptions for all six modes.

New player packages become available after the Windows/Linux release checks finish. Updating the Hub catalog then starts its self-update automatically.
